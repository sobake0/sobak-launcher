Privacy Policy

Last updated: September 4, 2026

본 개인정보처리방침은 SOBAK Launcher에서 Microsoft 계정 인증 및 Minecraft 서비스 이용 과정에서 처리되는 정보에 대해 설명합니다.

1. Microsoft Account Authentication

SOBAK Launcher는 Minecraft 계정 인증을 위해 Microsoft의 공식 인증 시스템을 사용합니다.

Microsoft 계정 로그인 과정은 Microsoft에서 제공하는 로그인 페이지를 통해 진행됩니다.

SOBAK Launcher는 사용자의 Microsoft 계정 비밀번호를 직접 요청하거나 수집하거나 저장하지 않습니다.

2. Information Used

로그인 및 Minecraft 계정 확인을 위해 Microsoft 인증 과정에서 제공되는 인증 정보가 사용될 수 있습니다.

이러한 정보는 사용자의 Microsoft 및 Minecraft 계정을 인증하고 게임을 실행하기 위한 목적으로만 사용됩니다.

3. Authentication Tokens

Microsoft 인증 과정에서 발급되는 인증 토큰은 로그인 상태 유지 및 Minecraft 서비스 인증을 위해 사용될 수 있습니다.

인증 토큰은 사용자의 Microsoft 계정 비밀번호가 아니며, Microsoft 인증 시스템에서 발급되는 제한된 인증 정보입니다.

4. Data Sharing

SOBAK Launcher는 사용자의 개인정보를 판매하지 않습니다.

Minecraft 계정 인증에 필요한 경우를 제외하고 Microsoft 인증 정보를 광고 또는 마케팅 목적으로 제3자에게 제공하지 않습니다.

5. Purpose of Use

처리되는 정보는 다음 목적으로 사용됩니다.

  • Microsoft 계정 인증
  • Minecraft 소유 여부 및 프로필 확인
  • Minecraft 게임 실행
  • SOBAK Minecraft 서버 이용

6. Third-Party Services

SOBAK Launcher는 Microsoft 및 Mojang의 서비스를 이용하여 Minecraft 계정 인증을 처리합니다.

해당 서비스의 개인정보 처리에는 Microsoft의 개인정보처리방침이 적용될 수 있습니다.

7. Changes to This Policy

SOBAK Launcher의 기능 또는 인증 방식이 변경될 경우 본 개인정보처리방침도 수정될 수 있습니다.
