SOBAK Launcher

SOBAK Launcher는 SOBAK Minecraft 서버 이용을 위해 제작된 커스텀 Minecraft Launcher입니다.

About

SOBAK Launcher는 사용자가 Minecraft를 간편하게 실행하고 SOBAK 서버를 이용할 수 있도록 제작된 런처입니다.

Microsoft Authentication

SOBAK Launcher는 Minecraft 계정 인증을 위해 Microsoft의 공식 계정 인증 시스템을 사용합니다.

SOBAK Launcher는 사용자의 Microsoft 계정 비밀번호를 직접 수집하거나 저장하지 않습니다.
